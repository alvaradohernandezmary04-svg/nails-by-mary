# Nails by Mary

Website for **Nails by Mary**, handmade luxury nail art.

## What's here

- `index.html`: the website (one page: home, about, collections, how to order, sizing guide, contact)
- `styles.css`: colors, fonts and layout
- `assets/logo.svg`: the butterfly logo

## Editing

Text in `[square brackets]` is a placeholder. Replace it with real details such as prices, photos and contact links.

## Viewing

Open `index.html` in a browser. When GitHub Pages is turned on, the site is live at
`https://<your-username>.github.io/nails-by-mary/`.
